1. HTML Structure and Useful Tags

HTML gives a webpage its structure and meaning.

10 HTML tags I find most useful

  1. <div> - groups content into sections.
  2. <span> - groups small inline pieces of content.
  3. <h1> - main page heading.
  4. <p> - paragraph text.
  5. <a> - creates links.
  6. <img> - displays images.
  7. <ul> - unordered list.
  8. <li> - list item.
  9. <button> - clickable button.
  10. <section> - separates meaningful page sections.

2. SEO Basics

SEO stands for Search Engine Optimization. Good page titles, descriptions, headings, and semantic HTML help search engines understand a webpage.

Important tags for SEO

  • <title> - tells search engines and users the page title.
  • <meta name="description"> - summarizes the page.
  • <h1> - describes the main topic of the page.
  • <h2> and <h3> - organize page sections.
  • <meta name="robots"> - gives crawling/indexing instructions.
  • <link rel="canonical"> - can identify the preferred URL for duplicate pages.

Font Size Units

  • 12px - I would use pixels when I want a small exact size, such as a caption.
  • 16pt - Points are more common for print-like content.
  • 1em - I would use em when the size should depend on the parent element.
  • 1.25rem - I would use rem for consistent text sizing across a page.
  • 120% - Percent is useful when I want text relative to its inherited size.
  • 2vw - Viewport width can be useful for text that scales with the browser width.

When I would use them

  • Static: normal text and page sections.
  • Relative: slightly moving an element or giving an absolute child a reference point.
  • Absolute: labels, badges, or icons placed inside a container.
  • Sticky: headers or controls that should remain visible while scrolling.
  • Fixed: elements that should remain attached to the browser window, such as this footer.
